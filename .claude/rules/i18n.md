# Languages in the app: hy, ru, en (rule 14)

## In code
- User-facing strings (UI, verdicts, advice, report, CLI) go through `i18n.t("group.name", **params)`.
- Add a key to `locales/hy.py` first, then to `ru.py` and `en.py` (the `translator` subagent), with the
  same `{placeholders}`.
- Lookup: current language → `en` → the key itself.
- The old inline Armenian strings move to keys in WL-21 … WL-26. Don't add new inline ones.
- The default language is `hy` until WL-30 reads the OS locale.
- `set_language()` raises `ValueError` for an unknown code.
- Planned (I18N epic): switch the language in the window and remember the choice.

## Tone and terms
- Informal and direct: hy `դու`, ru `ты`, en "you".
- Keep gamer and network terms as the Armenian UI does: ping, packet loss, jitter, relay, router and
  provider in Latin script.
- The full style guide is in `.claude/agents/translator.md`.
